# Residual risks

SQLite tasks, notes and chat history are not encrypted at rest. UI app lock does not protect home-screen widgets, native quick capture or lock-screen notification surfaces. Device backup is disabled, so automatic cloud restore of DAYNIX data is unavailable. Firebase login is optional and does not create account-scoped data storage. Gemini and speech recognition need network/device services where provided by the phone; offline speech is not guaranteed. Exact alarm, overlay, lock-screen display and TTS behavior depend on Android and device settings. Debug-signed builds are test artifacts. A rooted device can bypass client-side controls. Backend security controls, payment controls, and Play Integrity server verification are not applicable or unconfigured here.
